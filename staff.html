Staff dashboard (demo)

The back-office side of the site: every booking, message and member in one place.

Demonstration only, and there is no login. A real staff dashboard would sit behind a login on a server. This one is here to show the other side of the booking system: it reads the same browser storage as the booking form, so every booking, message and member you create on this site appears below straight away.

Your browser is blocking site storage, so nothing can be saved or listed here. Allow site data for this page and reload.

You opened this page from a folder on your computer. Some browsers, Firefox in particular, keep the saved data of each local file apart, so a booking may not show up on the next page. If that happens, open the live website, or run python3 -m http.server in the project folder and visit http://localhost:8000.
